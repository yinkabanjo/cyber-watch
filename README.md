# Cyber Attack Watch — data

Data behind SprintRight Technologies' public tracker of significant cyberattacks:
**https://sprintright.tech/cyber-watch/**

Updated weekly (Mondays, Lagos time) by an automated sweep of public reporting.

| File | Contents |
|---|---|
| `data/incidents.json` | One row per incident: date reported, type, sector, countries, threat actor, attribution, vulnerability/CVE, scale, AI involvement, status, source link |
| `data/advisories.json` | Government and agency warnings, attributions and preparedness advice |
| `data/sweep_log.json` | One row per sweep: when it ran, window covered, what it added |

Attributions and figures are as reported by the linked sources; they are not SprintRight's own findings.
Corrections: consultation@sprintright.tech
